# 💸 Sobra - App de Finanças para Pequenos Empresários

## 📌 Prompt Final (PRD)
# Contexto
Quero criar um aplicativo de organização financeira para pequenos empresários de comunidades, com pouco conhecimento digital.  
A ideia é permitir que eles acompanhem suas vendas, ganhos e o que realmente sobra, de forma simples e acessível.

# Problema
Muitos empreendedores locais não conseguem controlar suas finanças porque os apps atuais são complexos e exigem conhecimento técnico.  
Eles precisam de uma solução prática, sem burocracia, que funcione como uma conversa.

# Público-Alvo
Pequenos empresários de comunidades locais, com pouco conhecimento digital, que querem entender melhor seus ganhos e sobras reais.

# Funcionalidades-Chave
1. Registrar vendas e despesas via chat em linguagem simples.  
2. Calcular automaticamente o total de ganhos e o lucro líquido.  
3. Gerar relatórios básicos e visuais fáceis de entender.  
4. Oferecer dicas rápidas de organização financeira adaptadas ao perfil do usuário.  
5. Acompanhar resultados diários, semanais e mensais sem planilhas.

# Entregável da IA
Gerar um plano de MVP com:
- Fluxo de telas simples e intuitivas.  
- Recursos necessários para registrar vendas e calcular sobras.  
- Um esboço de validação inicial para medir se o app ajuda os pequenos empresários.
